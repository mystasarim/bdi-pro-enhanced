# BDI Pro Enhanced – Stable Integration

This branch (`fix/stable-enhanced`) will carry the **modular, UTF-8 clean, PHP 7.4+ compatible** plugin structure that replaces `bdi_complete_final.php` monolith.

## What’s included
- Helpers (Cache Manager, Rate Limiter, Logger)
- Category & Attribute handlers
- Importer (URL processing, image/WebP), Frontend tabs, Admin UI
- Deepseek compatibility layer: shortcodes, legacy AJAX action names, tab proxy callbacks
